# Proyek Sobat Bimbel Semester 2

- Kode Tim: IF-2MA-07
- Judul: Pengembangan Sistem Informasi Sobat Bimbel

## Deskripsi Permasalahan
Pengembangan Sobat Bimbel pada semester 2 difokuskan pada peningkatan fitur akademik dan pengelolaan operasional bimbingan belajar yang lebih kompleks. Sistem dikembangkan menggunakan framework Laravel agar aplikasi lebih terstruktur, scalable, dan mudah dikembangkan.

Pada tahap ini, fitur tambahan seperti absensi siswa, manajemen kursus, pengelolaan materi pembelajaran, dan peningkatan dashboard admin mulai diterapkan. Sistem juga dirancang agar mendukung pengelolaan data yang lebih terintegrasi antara admin, guru, dan siswa.

Pengembangan ini bertujuan untuk meningkatkan efisiensi proses akademik, mempermudah monitoring kegiatan belajar, dan menyediakan sistem informasi yang lebih modern dibandingkan versi sebelumnya.
